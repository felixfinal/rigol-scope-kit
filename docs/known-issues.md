# 已知问题

## KI-001：近零相位的仪器时差无效

两路接近同相时，仪器 RRDelay/RRPhase 曾返回 `9.9e37` 一类无效哨兵值。
工具保留 raw evidence，转换结果为 null 并标记 valid=false，不报告成零或测量成功。
90/180° 仪器读数有效；同记录的离线正弦拟合可得到有效近零相位（曾约 0.28°）。
根因未确认，目前作为非阻塞已知问题保留，不猜测为接地、固件或算法的确定故障。
需要精细近零相位时使用同记录、已知频率的离线拟合，并检查拟合质量和适用条件。

## 冻结记录的深度与通道数

冻结时从四通道切到两通道，设置 250M 后有效旧记录曾仍限制为 125M。
新 RUN 后才形成新的容量记录。导出旧事件不能偷偷 RUN；先读实际记录长度并报告限制。
若任务授权丢弃旧记录、重新采集，才重启采集并再次核对深度。

## 清理与锁的边界

普通任务的 release 是显式调用，不是自动退出钩子。
预约进程虽会到期清理，但强杀/网络故障时硬件状态仍可能未知；检查 cleanup_complete，再按授权恢复。
本机共享锁只协调本服务调用，不能防止前面板或其他主机干预。

## 分析与交付预算

深记录完整保存不代表可以一次全量分析：窗口/点数/时间/哈希预算分别限制。
已有数据分析不启动采集；需要更大范围时分窗，而不是绕过预算。
返回文件路径不等于产物已传到客户端；resource/artifact 读取和哈希检查是交付步骤。
