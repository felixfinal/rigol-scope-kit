# 能力与边界

公开整理版 0.6.1 保持 0.6.0 的仪器控制接口，41 个工具。实时工具列表和 `scope_contract` 是机器可读能力来源。

| 领域 | 当前支持 | 限制 |
| --- | --- | --- |
| 身份/状态 | identify、options/capabilities、status、doctor、电源读回 | 非身份实机操作要求绑定序列号 |
| 模拟通道 | CH1–CH4；显示、倍率、1M/50 输入、DC/AC/GND、量程/偏置、OFF/20M/250M 带宽限制 | 倍率须匹配物理探头，50 Ω 线缆不自动意味着 50 Ω 输入 |
| 时基/采集 | 时基位置、NORM/AVER/PEAK/HRES、平均次数、显式深度；RUN/STOP/SINGLE | 硬件上限随启用通道和选件变化；原子 RAW 请求不接受 AUTO |
| 触发 | EDGE POS/NEG/RFAL；PULSE 正负/大于/小于/区间；AUTO/NORM/SING | 其他高阶及协议触发尚未实现 |
| 触发选项 | DC/AC/LFR/HFR 耦合、噪声抑制、8 ns–10 s Holdoff | 耦合目前限 EDGE 模拟通道；噪声抑制/Holdoff 限 EDGE/PULS |
| 测量 | 频率、周期、Vpp、min/max/mean/RMS、占空比、脉宽、上升/下降、双通道时差/相位 | 无效数值必须作为无效返回，不能当作零 |
| AFG | 双路 SIN/SQU/RAMP/DC/NOIS；频率、幅度、偏置、相位、占空比/对称性、负载约定、同步相位 | 缺少调制/突发/任意波上传；启用需新鲜参数摘要与允许电压范围 |
| 导出 | STOP 下 NORM/RAW WORD、小窗口/整份、多通道、块哈希/记录哈希 | 最大 4M 点/块、8 MB/块，单请求 max_bytes ≤2 GiB、截止时间 ≤900 s |
| 任务 | profile/合同、预览、原子采集、短时预约及刺激后收集 | 调用方决定重测，不自动调参/循环；无失败回滚 |
| 离线 | 目录/元数据、绘图、单通道测量/事件搜索、双通道边沿时差/正弦拟合 | 单通道窗口 ≤2M 点；双通道总计 ≤2M 点；没有深记录全流式总览 |
| 文件 | 截图、PNG、报告 JSON/Markdown、资源读取/分块读取 | 小记录 CSV 与选定窗口 CSV 有独立预算，不能把大记录直接转为全量 CSV |
| 生命周期 | 显式 wake、release：未用 AFG off + 深度 AUTO | MCP 尚无专用休眠工具；普通断线不保证收尾 |

AFG 输出的物理源阻抗为 50 Ω；软件 highz/50 是幅度标定的负载约定，不是可切换输出电阻。
在 50 Ω 约定下，开路电压约为设定负载电压的两倍。启用工具会据负载约定检查开路电压界限。
低频实测不能证明额定带宽下的输出精度。

## 深度选择

按观察时长 T 与目标采样率 Fs 估算 N ≥ T × Fs。
如果最短事件持续 W、希望每事件至少 K 点，需 Fs ≥ K/W。
选择足够覆盖目标的较小档位；上最大深度前预算传输、保存和后续分析成本。

500Mpts 选件下，启用 1/2/3–4 个通道时，上限分别为每通道 500M/250M/125M 点。
未启用该选件时对应 100M/50M/25M。
决定上限的是启用通道数量，不是本次导出通道数量。
更详细的预算、冻结记录行为与历史实测见 [Skill 深记录参考](../skills/rigol-oscilloscope/references/deep-records.md)。

## 未实现与待验收

未实现：runt、slope、timeout、setup/hold、协议触发；总线解码；PLA2216/数字通道；AFG 高阶功能；无人任务。
待验收：MHO934/MHO984、高频精度、双通道每路 250M 和四通道每路 125M 的整份导出；真实网络故障/强杀所有者的清理恢复。
跨 Agent 框架的委派回传应由集成端单独验收，MCP 测试不替代该验收。
