# 0.6.1 发布前审核

审核日期：2026-10-12。范围为公开源码、依赖/构建、MCP/CLI、Skill、文档和发布包；本轮不操作仪器。

## 结论

未发现阻止本次源码发布的问题。已修订发布包核验并完成本机验证。
实际 GitHub Actions 状态以该次运行结果为准；本机通过不能替代远端 CI。

## 审核与修订

- 仪器操作：非身份查询要求序列号绑定；写操作要求当前任务授权；AFG 开启检查新鲜设置摘要与开路峰值界限。
- 协作与故障：CLI/MCP 共用设备锁；预约所有者有截止时间、认证与清理回执；传输失联不自动重放刺激。
- 文件：记录 ID 和文件名有白名单；路径越界/符号链接拒绝；离线分析验证原始数据哈希并限制窗口与预算。
- 发布核验：先前对 sdist 主要检查顶层目录，对 wheel 主要检查必要文件，不能充分发现目录内额外文件或运行源码变化。现按公共源码的精确文件集合和字节内容核对，拒绝多余、缺失、重复、越界和变化的成员。
- 三项发布回归覆盖干净包、混入允许目录的私有文件、运行代码篡改。
- 已补上真实仓库 URL、克隆步骤和包元数据链接；CI 显式选择当前矩阵环境的解释器。
- 依赖保留 uv.lock，运行依赖版本未升级；不提交真实设备配置、凭据、采集数据或厂商 PDF。

## 已记录的边界
