# 先采集，再分析

1. 任务 Agent 明确通道与物理探头、预期电压/频率或事件宽度、需要的事件前后范围，以及要判断的问题。接线未知时保留未知，不能从 profile 推断物理接线。
2. 查询合同和 profile。选择符合接线的默认配置；将本轮决定写入 overrides，将预期信号写入 expected_signal。
3. 周期信号先用边沿触发。按目标设置触发源/极性/阈值，电压量程和偏移应容纳预期上下限。观察多个周期或单个边沿需要不同时间范围。
4. 结合窗口长度和最短事件选择采样深度，按需预览。存储深度、时基和开启通道共同影响采样率；不要把请求深度当作保证达到的采样率。
5. 一次原子采集后，先检查 verified、触发结果、actual_settings、截图与 quality，再选择静态记录分析窗口。未触发、削顶、窗口缺失和采样不足需分开报告。
6. 将 capture_id、收据、实际设置、来源、质量限制和分析证据返回任务 Agent。由它决定下一轮修改哪项以及理由；服务端不自动重抓。

## 参数选择的影响

- 输入 DC 保留直流分量；AC 会改变低频和直流信息。带宽限制会影响尖峰和边沿，不能仅为波形好看而默认滤掉目标。
- AVER 适用于重复信号降噪，可能隐藏非重复异常；HRES/PEAK 也应结合目标选择。profile 给出基线，调用方显式覆盖。
- 物理 10x 探头应匹配 probe_ratio=10。50 Ω 同轴线不等于通道应设 50 Ω；输入终端需要结合信号源和允许负载选择。
- RAW 读取停止后的记录；NORM 导出最多 1000 点。导出数据的有效时间分辨率按导出 preamble/时间范围计算，不能用较高 ADC 采样率代替。
- 截图帮助检查显示范围和触发位置；分析使用保存的原始点。图上的抽样/最小最大包络不替代原始数据测量。
- 长存储只在目标需要时启用；单次执行有等待、时间和字节预算，离线分析每次最多 2M 选中点。超过时由调用方选择窗口。

服务端不主动认定 DUT 通过。遇到证据不足应返回具体限制，例如“未触发”“只抓到一个不完整周期”或“导出间隔不足以解析目标脉冲”，而不是声称不存在事件。
