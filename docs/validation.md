# 验收范围与发布检查

## 历史实机验收

以下为 0.6.0 及之前阶段的 MHO954 实机证据摘要，依据项目维护记录整理。
0.6.1 是文档、发布与无配置合同查询修订；本轮没有再次唤醒或操作示波器，也未重新执行这些耗时采集。
硬件型号、选件、接线和固件改变后，应按使用场景重新验收。
原始私有记录没有放入公开仓库；下表不能代替另一台仪器的测量证明。

| 场景 | 已通过范围 |
| --- | --- |
| 基础操作 | 身份、选件、状态、截图、通道/时基、EDGE/PULSE、单次采集和仪器测量 |
| 双 AFG 10× 回接 | 1 MΩ 输入下低频正弦/方波；双通道 0/90/180°；仪器与离线拟合时差 |
| GII → CH2 50 Ω 同轴 | 1×、50 Ω 输入；1 kHz 正弦约 1000.45 Hz / 1.019 Vpp；方波约 1000 Hz / 1.025 Vpp / 50% 占空比 |
| 触发选项 | 耦合、噪声抑制、Holdoff 写入和读回 |
| 预约采集 | 先观测 WAIT、再开启 AFG；触发前后信号区分；占用拒绝、取消、到期清理、独立 SSH 客户端断开后清理 |
| 交还与电源 | 未用 AFG 关闭、深度 AUTO、配置保留、低功耗查询和显式唤醒 |

方波极值 Vpp 与稳定电平差可能不同，曾分别为约 1.025 V 和 0.992 V；工具分开报告，不把过冲当成稳定电平。
近零相位仪器测量的无效值见 [已知问题](known-issues.md)。

## 软件验证

单元测试覆盖 SCPI 分帧/截止时间、身份绑定、跨进程锁、配置联动、采集合同、错误回执、预约所有者和清理、数据哈希与离线质量/双通道时差。
测试使用假数据、loopback TCP 和本机子进程，不连接实际示波器。
发布检查还验证公共目录/包内容、离线 stdio MCP 发现、安装后 Skill 资源、wheel/sdist 元数据。
本轮实际检查结果写入发布包旁的验证记录；CI 工作流是准备好的检查入口，GitHub 上是否执行须看该次 Actions 结果。

## 单独待验收

- 双通道每路 250M、四通道每路 125M 整份导出。
- MHO934/MHO984 与高频精度；所有支持项在其他固件下的行为。
- 真实网络失联和强杀预约所有者后的硬件状态；目前模拟测试覆盖部分恢复分支。
- 集成端的跨 Agent 委派与结果回传；它不属于普通 stdio MCP 连通测试。
